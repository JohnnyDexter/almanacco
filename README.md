# ALMANACCO

Premium multilingual website for ALMANACCO, designed for Japanese customers and built with Astro + Tailwind CSS.

## Features

- Japanese default site with English and Italian localized routes.
- Luxury editorial visual system using ivory, charcoal, forest green, brass, and terracotta.
- Reusable layout, header, footer, language switcher, homepage, and page template components.
- SEO metadata, canonical URLs, alternate language links, robots.txt, sitemap placeholder, and favicon placeholder.
- GitHub Pages deployment workflow and Astro `base: '/almanacco'` configuration.
- Astro Content Collections schemas for future journal, product, and event content.

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

The project is intended to be installed and built on a machine with npm registry access.
